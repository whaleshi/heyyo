# Heyyo.club 前端设计（用户已确认）

范围：将独立 Tendies 前端适配为 Heyyo.club，只实现浏览器端，不实现后端、合约、真实交易或收益结算。

视觉：浅暖灰背景、白色圆角卡片、近黑文字、荧光绿主色、少量粉色。使用用户提供的挥手 Logo 原图。延续三列代币卡片和克制的间距，不新增大型营销区。桌面三列，手机标签切换单列。中英文完整切换，默认英文。

页面：首页（搜索、分类、排序、代币卡片、平台币与回购概览）；创建（图片、名称、符号、折叠可选字段、表单校验、确认预览、本地演示发布）；详情（示例价格图、买卖演示、进度、双平台标识、交易记录）；收益（已创建代币、收益记录）；机制（弹窗）。

机制严格使用用户输入：Ayoo 创作者手续费池的 70% 分配给 Heyyo；Heyyo 所收部分 50% 回购 HEYYO，50% 奖励创作者，即原创作者手续费池的 35%/35%。不将其表达成交易额的百分比，不编造其他 30% 的去向。双平台发布仅作为产品机制呈现，本地演示发布不得声称实际上链或同步 Ayoo。

状态：全站固定清晰的 Preview 标识；示例代币、指标、交易与收益明确标注。使用 localStorage 保存语言、本地创建代币、观察列表与演示余额/交易。钱包入口提供演示连接，不调用钱包注入对象、网络 API 或签名。未知代币显示返回入口。表单处理空值、长度、非法 URL、图片类型/大小和存储失败。交易演示处理金额、余额与持仓不足。

技术：复用 React/TypeScript/Vite。模块按模型、状态、布局、各页面划分；移除旧 Solana 程序调用。验证类型、生产构建、分配数学与交易输入，浏览器验证搜索、创建、交易、语言、刷新持久化和手机布局。
