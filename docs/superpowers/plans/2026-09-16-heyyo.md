# Heyyo Frontend Implementation Plan

> **For agentic workers:** Execute inline using executing-plans. User approved the design and requested implementation in this task.

**Goal:** Deliver a complete minimal Heyyo.club frontend with the uploaded logo.
**Architecture:** React application with typed demo state persisted locally, hash navigation and reusable accessible dialogs. No server or chain adapters.
**Tech Stack:** React 18, TypeScript, Vite, Lucide, Radix Dialog, Recharts, CSS.
**Spec:** ../specs/2026-09-16-heyyo-design.md

## Global Constraints
- Frontend only; no real transactions, wallet signatures, or network writes.
- Creator fee distribution: 70% to Heyyo, split 50% / 50% from that amount.
- Logo image stays unmodified; lime/black/off-white brand; responsive and bilingual.
- All invented data explicitly marked as preview/demo.
